# План: интерфейс и кеш библиотек

## Умный кеш списков

Цель: не дёргать сервисы без необходимости, но никогда не показывать устаревшие данные как подтверждённые.

- Хранение: `chrome.storage.local` (снимки библиотек, уже есть) + метаданные `{provider, fetchedAt, etag/revision, counts, collectionRevisions}`.
- Проверка свежести вместо полного чтения: дешёвый «пульс» каждого сервиса (Spotify — `total` из первой страницы и `snapshot_id` плейлистов; Apple — `meta.total` и дата изменения плейлистов; Яндекс — `revision` лайков и плейлистов; Звук — `collectionCount` и число плейлистов). Если пульс совпал с кешем, снимок считается актуальным без перечитывания.
- Пошаговое обновление: перечитываются только изменившиеся плейлисты; лайки читаются с начала только при смене счётчика или ревизии.
- TTL: показ кеша мгновенно при открытии, фоновая проверка пульса (не чаще раза в 10 минут на сервис), ручная кнопка «Обновить» читает заново.
- Состояния карточки: «свежий», «проверяется», «устарел» (кеш показан, обновление не удалось), «нет данных». Неподтверждённый снимок никогда не заменяет подтверждённый.
- Каталожный поиск уже кешируется (`match-cache.js`); добавить общий лимит размера и очистку по возрасту, кнопку «Очистить кеш» с подсчётом занятого места.

## Интерфейс

- Экран входа: четыре карточки сервисов, статус, число лайков/альбомов/плейлистов, кнопка «Войти», кеш-метка «обновлено N минут назад».
- Выбор «откуда → куда» одним жестом (обмен направлением), чипы «Лайки», «Альбомы», «Плейлисты» с галочками и счётчиками; можно выбрать отдельные плейлисты и альбомы.
- Список треков: обложки, поиск и фильтры (все / авто / на проверку / не найдено / исключённые), сортировка, виртуальный список, групповые действия, предпрослушивание не требуется.
- Интерактив по трекам: развернуть кандидатов, выбрать другой вариант, ввести свой запрос, исключить, вернуть, открыть в сервисе, клавиатура (стрелки, Enter, Space, Esc).
- Ход переноса: сводка до записи (лайки/альбомы/плейлисты, пропуски), прогресс по этапам, пауза при 429 с обратным отсчётом, отмена, итоговый отчёт с экспортом пропусков.
- Оформление: светлая и тёмная темы, адаптивность до 320 px, доступность (контраст, фокус, aria), анимации без лишнего движения (`prefers-reduced-motion`).
