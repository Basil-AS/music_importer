# Локальный read-only коннектор Звука

Расширение читает метаданные из ответов GraphQL, которые сама страница Звука получает в активной пользовательской сессии. Поддерживаются «Любимое», каталог плейлистов и их треки. Сырые ответы, пароли, cookies, токены, GraphQL-заголовки и cursor не сохраняются; запросы к серверу проекта отсутствуют.

## Ручной запуск

1. В Chrome откройте `chrome://extensions`, включите Developer mode и нажмите **Load unpacked**, выбрав каталог `chrome-extension/`.
2. Войдите на `zvuk.com` обычным способом.
3. Откройте любую страницу `zvuk.com`, нажмите значок расширения → **Собрать библиотеку целиком**.
4. Расширение последовательно загрузит `/favorites`, `/collection` и каждую страницу найденного плейлиста. Не закрывайте вкладку до завершения.
5. Popup показывает, подтверждён ли полный сбор. Скачайте один файл `zvuk-library.json` с лайками и плейлистами или отдельные `zvuk-favorites.json` / `zvuk-playlists.json`; библиотеку одним файлом можно загрузить в локальный match-review экран.

## Что подтверждается

- Избранное дедуплицируется по Zvuk track ID. Сбор помечается подтверждённым только при завершённой cursor-пагинации и совпадении количества с независимым `getCollectionIds`.
- Каталог плейлистов подтверждается при совпадении числа уникальных элементов с независимым счётчиком и отсутствии следующей страницы.
- Плейлист подтверждается, если получено известное число элементов и позиции непрерывны от нуля. Неполные списки остаются явно помеченными и не считаются готовыми.
- В playlist JSON сохраняются исходные ID, порядок и повторяющиеся элементы. Демо строит preview-действия для лайков и добавления в плейлисты, но пока ничего не записывает в Apple Music.
- Один запуск объединяет сбор избранного и playlist catalog. Перед переходом к следующему шагу проверяются независимые totals; при остановке, ошибке или расхождении scan получает статус `needs_review` и не объявляется полным.

## Ограничения и безопасность

- Сбор основан на частных и изменяемых GraphQL-операциях Звука: `getPaginatedCollection`, `getPaginatedCollectionAll` / `getPaginatedCollectionAllSections`, `getPlaylistTracks`, `getPlaylists`, `getCollectionIds`. Формы ответов могут измениться. Фоновая обработка браузера, новая версия API или медленная загрузка могут оставить отдельный плейлист неполным; JSON обязан сохранить это состояние.
- Расширение использует только host permission `https://zvuk.com/*` и разрешения `activeTab`, `storage`, `unlimitedStorage`. Оно не запрашивает `cookies` или `webRequest`, не читает учётные данные и не внедряет новые запросы в аккаунт.
- Нормализованные музыкальные метаданные хранятся в `chrome.storage.local` до ручной очистки или удаления расширения. Chrome не шифрует это хранилище. Пользователь сам решает, когда скачать файл.
- Проектный UI ищет кандидатов в Apple iTunes Search API. Это не вход в Apple Music и не запись в библиотеку. Текущий план показывает ноль выполненных записей.
- Автоматизация использует обычную загрузку/прокрутку страницей Звука, чтобы веб-приложение само выполнило свои GraphQL-запросы; это частный и изменяемый API. Коннектор не читает или не сохраняет секреты сессии.
- Обновлённый one-click scan ещё не был проверен на установленном расширении и живой сессии. Перед массовым использованием сверьте числа и статусы на своём аккаунте.
