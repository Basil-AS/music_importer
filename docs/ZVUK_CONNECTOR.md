# Локальный read-only коннектор Звука

Первый browser connector читает только список избранных треков из открытой страницы `https://zvuk.com/favorites`. Он использует запросы, которые уже выполняет сайт в пользовательской сессии, и передаёт локальному расширению только выбранные метаданные треков и счётчик контрольного списка. Пароли, cookies, access token, GraphQL headers, сырые тела ответов и cursor не читаются расширением и не сохраняются. Запросы к серверу проекта отсутствуют.

## Запуск для ручного ознакомления

1. Откройте `chrome://extensions`, включите Developer mode и выберите **Load unpacked** → каталог `chrome-extension/`.
2. Обычным способом войдите на `zvuk.com`, затем откройте страницу «Любимое».
3. Нажмите значок Music Importer и **Начать сбор избранного**. Страница перезагрузится, чтобы установить наблюдатель до загрузки данных.
4. Прокрутите «Любимое» до конца. Popup показывает число пойманных страниц и distinct track IDs; полнота подтверждается только когда закончилась cursor-пагинация и число совпало с независимым `getCollectionIds`.
5. Скачайте `zvuk-favorites.json`, импортируйте его в демо Music Importer и продолжите каталожное сопоставление.
6. Нажмите «Остановить» и при необходимости «Очистить локальные данные». `chrome.storage.local` очищается также при удалении расширения.

## Сбор и ограничения

- Разрешение ограничено доменом `zvuk.com`; вкладка ограничена маршрутом `/favorites`. Расширение использует `activeTab`, `storage` и `unlimitedStorage`, не просит `cookies`, `webRequest`, доступ к паролям или всем сайтам. Доступ к `storage.local` ограничен trusted extension contexts.
- Наблюдатель работает в MAIN world только для распознавания ответов `/api/v1/graphql` операций `getPaginatedCollection` и `getCollectionIds`. Он не изменяет запросы сайта, не добавляет auth headers и не обходит WAF.
- `getPaginatedCollection` курсорный, но сайт сам загружает следующие страницы при прокрутке; поэтому сбор не завершится, пока пользователь не доведёт список до конца. Если независимый count не получен или counts расходятся, экспорт помечается неподтверждённым.
- Применяется дедупликация по Zvuk track ID, но исходный порядок пока равен порядку первого появления страниц. Checkpoint/resume страницы и playlists ещё не реализованы.
- Выгрузка включает только избранные треки и основные metadata. Она не пишет ничего в Звук или другой аккаунт. Apple-каталог prototype пока только строит preview plan; записывающие adapters ещё предстоит сделать.
- API Звука частный и может поменяться. GraphQL cursor, поля и count cross-check в проекте основаны на проверках 27.10.2026; runtime verification этого расширения на живой сессии пока не выполнялась.

## Данные

В `chrome.storage.local` остаются нормализованные IDs, названия, исполнители, длительность, explicit/availability и release title, пока пользователь не очистит состояние или не удалит extension. Chrome хранит `storage.local` локально, но не шифрует его; поэтому содержимое — только track metadata, без bearer-токена и cookie. Скачать файл — явное действие пользователя; файл содержит библиотечные metadata и остаётся на его устройстве, если он сам не переместит/отправит его.
