# Интерактивный MVP

## Что можно попробовать

1. Выбрать сервис, откуда взят экспорт. Это подпись источника, вход в аккаунт пока не выполняется.
2. Загрузить демонстрационный список или свой CSV/JSON-файл с полями названия и исполнителя.
3. Искать композиции в каталоге Apple. Для каждого трека запрос можно поправить вручную; доступные версии нужно выбрать самому.
4. Исключить ненужные треки или нажать «Выбрать совпадения».
5. Скачать JSON-план с Apple Music track ID, ссылками, выбранными совпадениями и пропусками.

## Данные и границы

- CSV и JSON читаются браузером и не отправляются на сервер проекта.
- Поиск обращается напрямую из браузера к публичному Apple iTunes Search API. Apple получает введённые названия и исполнителей. Поддерживаются storefronts AE, US, GB, CA и AU.
- Поиск может возвращать похожие версии или неполные результаты. Каждый вариант нужно проверить вручную; для неточного поиска поле запроса можно изменить.
- План описывает желаемые действия `favorite`, но ни одна запись в Apple Music не выполняется. В файле явно указано `appleMusicWritesPerformed: 0`.
- Вход и импорт лайков из Spotify, Звука и Яндекс Музыки не подключены. Нужно сначала выгрузить свой список треков в CSV/JSON.

## Запуск

Из корня проекта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory demo
```

Открыть <http://127.0.0.1:8000>. Для сетевого поиска нужен локальный HTTP-сервер: при открытии `index.html` как `file://` браузер может заблокировать запрос к каталогу.

## Ручная проверка

В браузере проверены загрузка CSV с двумя треками, поиск Apple для демонстрационного списка, выбор `Daft Punk — One More Time`, формирование и скачивание JSON. В скачанном плане присутствовал Apple track ID `697195462`; `appleMusicWritesPerformed` равнялся `0`.
