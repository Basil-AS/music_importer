# Chrome Web Store: материалы листинга

Публикация выполняется владельцем developer account в [Developer Dashboard](https://chrome.google.com/webstore/devconsole). Загрузка и отправка на review — отдельное действие владельца; здесь только подготовленные материалы. Требования: [Prepare your extension](https://developer.chrome.com/docs/webstore/prepare), [Program policies](https://developer.chrome.com/docs/webstore/program-policies/policies).

## Архив

```bash
scripts/package-extension.sh   # distribution/music-importer-<версия>.zip, manifest.json в корне
```

## Описание (до 132 символов)

Перенос лайков, альбомов и плейлистов между Spotify, Apple Music, Яндекс Музыкой и Звуком из ваших открытых вкладок.

## Подробное описание

Music Importer читает вашу библиотеку в открытых вкладках Spotify, Apple Music, Яндекс Музыки и Сбер.Звука и переносит её в любой другой из этих сервисов: лайки остаются лайками, альбомы — альбомами, плейлисты — плейлистами с сохранением порядка. Треки сопоставляются автоматически (ISRC, название, исполнитель, длительность, версия); вручную проверяются только спорные. Перед записью показывается сводка, после записи результат сверяется чтением обратно.

Вход выполняется на сайтах сервисов как обычно. Расширение не запрашивает пароли, не читает cookie и не отправляет вашу библиотеку на сервер: данные остаются в браузере.

## Обоснование разрешений (single purpose: перенос музыкальной библиотеки)

| Разрешение | Зачем |
| --- | --- |
| `storage`, `unlimitedStorage` | Локальные снимки библиотек, кэш сопоставлений, журнал переноса |
| host: `open.spotify.com`, `music.apple.com`, `music.yandex.ru`, `api.music.yandex.ru`, `zvuk.com`, `itunes.apple.com` | Запросы от имени вашей сессии на страницах сервисов; публичный поиск iTunes |
| host: `basil-as.github.io` | Резервный веб-интерфейс на GitHub Pages |
| optional host: `127.0.0.1`, `localhost` | Только для запасного локального интерфейса; основной не требует |
| content scripts | Мост между страницей сервиса и расширением на указанных доменах |

## Раскрытие данных (Privacy practices)

- Обрабатываются: названия треков, альбомов, исполнителей, плейлисты и лайки пользователя; данные сессии остаются в памяти вкладки сервиса.
- Не продаются, не передаются третьим лицам, не используются вне основной функции; собственного сервера нет.
- Политика конфиденциальности: `demo/privacy.html` (после включения Pages — `https://basil-as.github.io/music_importer/privacy.html`). Для листинга нужен публичный URL.
