# Перенос музыки

Локальный интерактивный MVP для подготовки переноса лайков в Apple Music.

## Быстрый старт

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory demo
```

Откройте <http://127.0.0.1:8000>. Можно также открыть `demo/index.html` напрямую.

Можно загрузить демонстрационные данные или свой CSV/JSON список треков, вручную проверить названия, выбрать нужные строки и скачать JSON-план. Исходный файл обрабатывается в браузере и никуда не отправляется.

Поддерживаемый CSV: столбцы `title,artist` (также понимаются `Track Name,Artist Name(s)` и русские `название,исполнитель`). JSON — массив объектов с `title`/`artist` либо `tracks`, `items` или `data` с таким массивом. Для объектов с вложенным `track` поля также распознаются.

Это MVP-подготовка: вход в сервисы, автоматический поиск каталога Apple Music и запись лайков пока не реализованы. Демо-сопоставления — примеры, а не запросы в Apple Music. Перед следующим этапом изучения авторизации и реальных API см. `docs/`.
