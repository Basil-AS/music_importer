# Перенос музыки

Интерактивный прототип импорта лайков из музыкальных сервисов в Apple Music.

## Быстрый старт

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory demo
```

Откройте <http://127.0.0.1:8000>. Можно также открыть `demo/index.html` напрямую.

Прототип работает с демонстрационным каталогом: он не подключается к аккаунтам и не меняет библиотеки. Описание текущих исследований API лежит в `docs/`.
