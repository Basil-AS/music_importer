# Перенос музыки

Локальный интерактивный прототип сопоставления треков. Цель продукта — переносить лайки и плейлисты между любыми двумя сервисами из Spotify, Apple Music, Яндекс Музыки и Звука; этот прототип пока реализует только файловый импорт и поиск в каталоге Apple.

## Быстрый старт

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory demo
```

Откройте <http://127.0.0.1:8000>. Сервер нужен для поиска в каталоге Apple; при открытии HTML напрямую браузер может заблокировать сетевой запрос.

Запускайте сервер из checkout ветки `feature/interactive-importer-mvp`. Если параллельно переключаете основную папку проекта на ветку исследования, держите MVP в отдельном Git worktree: при переключении ветки каталог `demo/` исчезает из checkout, и оставшийся сервер начинает отвечать `404`.

Можно загрузить демо-данные, CSV/JSON или получить подтверждённую библиотеку Звука напрямую из локального Chrome-расширения. Затем найти версии в каталоге Apple, автоматически принять только очевидные совпадения и проверить спорные. Источник/файлы обрабатываются локально; поиск передаёт Apple названия и исполнителей.

Поддерживаемый CSV: обязательные `title,artist`, дополнительные `album,isrc,duration_ms,id` (также понимаются `Track Name,Artist Name(s)` и русские `название,исполнитель`; разделители запятая, точка с запятой или табуляция). JSON — массив объектов с `title`/`artist` либо `tracks`, `items` или `data` с таким массивом. Для объектов с вложенным `track` поля также распознаются. Общая provider-neutral модель snapshot/plan находится в [`demo/transfer-core.js`](demo/transfer-core.js), общий контракт поиска и постраничного чтения — в [`demo/transfer-engine.js`](demo/transfer-engine.js), контракт account adapters — в [`docs/ADAPTER_CONTRACT.md`](docs/ADAPTER_CONTRACT.md). Они принимают ID четырёх сервисов, сохраняют playlist order и различают целевые действия likes/playlists. Сейчас подключён только Apple catalog search; account adapters и запись не подключены.

Это прототип этапа чтения Звука и сопоставления, а не готовый универсальный перенос: остальные аккаунты, целевые адаптеры и запись в пользовательские библиотеки пока не реализованы. Каталог Apple доступен через публичный Apple iTunes Search API; matcher автоматически принимает только высокоуверенные уникальные результаты, а спорные требует проверить. Сформированный JSON пока является планом, не выполненным переносом. Исследования API и авторизации всех сервисов ведутся в отдельном PR.

Подробности сценария и границ прототипа: [`docs/MVP.md`](docs/MVP.md). Правила сопоставления и ограничения confidence: [`docs/MATCHING.md`](docs/MATCHING.md).

Первый локальный browser connector для чтения избранного и плейлистов Звука находится в [`chrome-extension/`](chrome-extension/) и описан в [`docs/ZVUK_CONNECTOR.md`](docs/ZVUK_CONNECTOR.md). После полного сбора подтверждённую библиотеку можно передать в открытую локальную страницу без промежуточной загрузки файла. Коннектор остаётся read-only; живой аккаунт не проверен. Коннекторы Spotify, Apple Music и Яндекс Музыки, а также запись в пользовательские библиотеки пока отсутствуют.
