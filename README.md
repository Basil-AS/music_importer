# Перенос музыки

Локальный интерактивный прототип сопоставления треков. Цель продукта — переносить лайки и плейлисты между любыми двумя сервисами из Spotify, Apple Music, Яндекс Музыки и Звука; этот прототип пока реализует только файловый импорт и поиск в каталоге Apple.

## Быстрый старт

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory demo
```

Откройте <http://127.0.0.1:8000>. Сервер нужен для поиска в каталоге Apple; при открытии HTML напрямую браузер может заблокировать сетевой запрос.

Запускайте сервер из checkout ветки `feature/interactive-importer-mvp`. Если параллельно переключаете основную папку проекта на ветку исследования, держите MVP в отдельном Git worktree: при переключении ветки каталог `demo/` исчезает из checkout, и оставшийся сервер начинает отвечать `404`.

Можно загрузить демонстрационные данные или свой CSV/JSON список треков, найти версии песен в каталоге Apple, вручную выбрать совпадения и скачать JSON-план. Файл обрабатывается в браузере и никуда не отправляется. Поиск передаёт Apple названия и исполнителей треков.

Поддерживаемый CSV: столбцы `title,artist` (также понимаются `Track Name,Artist Name(s)` и русские `название,исполнитель`; разделители запятая, точка с запятой или табуляция). JSON — массив объектов с `title`/`artist` либо `tracks`, `items` или `data` с таким массивом. Для объектов с вложенным `track` поля также распознаются.

Это прототип одного этапа, а не MVP заявленного универсального переноса: подключение аккаунтов, каталоги других сервисов и запись коллекций в любое назначение пока не реализованы. Каталог Apple доступен для поиска через публичный Apple iTunes Search API; результаты требуют ручной проверки. Сформированный JSON — план, а не выполненный перенос. Исследования API и авторизации всех сервисов ведутся в отдельном PR.

Подробности сценария и границ MVP: [`docs/MVP.md`](docs/MVP.md).
